# pjman
> ⚠️ 開発初期段階、安定版はありません

[English](./README.md) | [中文](./README-zh.md) | [한국어](./README-ko.md)

pjman は開発初期段階にある、Rust で実装されたローカルプロジェクトディレクトリ管理用 CLI ツールです。開発者が散らかって分類しにくいプロジェクトフォルダを整理するのを支援します。

ロードマップ：最初の公開リリース前にサービスモードを実装する予定です。
データベース接続、AIエージェントや外部サービスから利用可能な OpenAPI、AI から呼び出せる MCP 機能を公開します。

多くの開発者が同じ悩みを抱えています。Mac / Windows / Linux 上の数十～数百のローカルプロジェクトが一箇所に詰め込まれたり、ディスク上にバラバラに散らばったりして探しにくく、`ls` や `cd` を何度も打って移動するのが面倒です。

pjman はこの課題を解決するために作られました。ワークスペースを作成し、プロジェクトを登録できます。
- `pjman jump kubernetes`：対象プロジェクトディレクトリへ移動
- `pjman jump --select ProgrammingLanguage=Java KlassOf=OpenSource License=MIT`：タグ条件に一致するプロジェクトへ移動、複数該当する場合は選択画面を表示

特に重要な点として、pjman は AI コーディングエージェントにも同じ管理機能を提供し、AI が多数の進行中ローカルプロジェクトを自然に扱えるようにします。
