# pjman
> ⚠️ 초기 개발 단계, 안정 버전이 없습니다

[English](./README.md) | [中文](./README-zh.md) | [日本語](./README-ja.md)

pjman은 초기 개발 단계에 있는 Rust 기반 로컬 프로젝트 디렉터리 관리 CLI 도구입니다. 개발자가 어수선하고 분류하기 어려운 프로젝트 폴더를 정리할 수 있도록 돕습니다.

로드맵: 첫 공개 릴리즈 전까지 서비스 모드를 구현할 계획입니다.
데이터베이스 연결, AI 에이전트와 외부 서비스가 호출할 수 있는 OpenAPI, AI가 사용 가능한 MCP 기능을 노출합니다.

많은 개발자가 같은 불편함을 겪습니다. Mac, Windows, Linux에 있는 수십~수백 개 로컬 프로젝트가 한 폴더에 몰려 있거나 디스크 여기저기에 흩어져 찾기 어렵고, `ls`, `cd`를 반복해서 쓰는 작업이 번거롭습니다.

pjman은 이 문제를 해결하기 위해 만들어졌습니다. 워크스페이스를 만들고 프로젝트를 등록할 수 있습니다.
- `pjman jump kubernetes`: 대상 프로젝트 디렉터리로 이동
- `pjman jump --select ProgrammingLanguage=Java KlassOf=OpenSource License=MIT`: 태그 조건에 일치하는 프로젝트로 이동, 여러 개가 검색되면 선택 목록 제공

가장 중요한 점은 pjman이 AI 코딩 에이전트에도 이 관리 기능을 제공해서, AI가 진행 중인 수많은 로컬 프로젝트를 자연스럽게 다룰 수 있게 해준다는 것입니다.
